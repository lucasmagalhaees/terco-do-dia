# terco-do-dia

App web (HTML único, funciona offline no celular) que acompanha o terço do dia em português, latim ou os dois lado a lado.

- Escolhe os mistérios pelo dia da semana (gozosos, luminosos, dolorosos, gloriosos), com troca manual
- Terço virtual animado: a câmera acompanha a conta atual
- Modo Auto com velocidade Normal ou BS (mais rápida)
- Progresso do dia salvo no navegador

Para usar, abra o `index.html`.
